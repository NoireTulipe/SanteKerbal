# Mod KSP : KerTech by NoireTulipe (anciennement SanteKerbal)
- Mod pour Kerbal Space Program 1.12.x (Unity 2019, C#, cible net472)
- Compiler : `dotnet build src -c Release` (déploie dans GameData/KerTech du jeu)
- KSP installé dans : C:\Program Files\GOG Galaxy\Games\Kerbal Space Program
- Logs du jeu : KSP.log à la racine de l'installation (préfixe `[KerTech]`)
- Objectif : la tablette KerTab (plateforme d'applications) et la vie à bord (santé, eau, nourriture, G, chaleur, hibernation, navigation)
- Organisation : GameData/KerTech/{KerTab, VieABord, Plugins}, réglages dans KerTech.cfg
