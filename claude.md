# Mod KSP : SanteKerbal
- Mod pour Kerbal Space Program 1.12.x (Unity 2019, C#, cible net472)
- Compiler : `dotnet build src -c Release`
- KSP installé dans : C:\Program Files\GOG Galaxy\Games\Kerbal Space Program
- Logs du jeu : KSP.log à la racine de l'installation
- Objectif : simuler la santé des Kerbals (G, chaleur, faim, soif)
